# geoquiz-japan

地図とChat GPTを融合したAndroidのQuizゲームアプリです。ユーザが難易度を「簡単」「難しい」「超難しい」から選び地図をタップすると、タップした住所から難易度に合わせてQuizを生成します。4択問題の回答した後、正解・不正解の判定を行います。

地図表示：MapBox Maps SDK for Mobile

座標から住所生成：Yahoo! ReverseGeoCoder API

Quiz生成：ChatGPT API

開発環境：Android Studio

開発言語：Kotlin

Approduce： https://apps.approduce.corp.yahoo.co.jp/upload/13802
